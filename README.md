One joke about Monday mornings, 74 characters, written by a small Python program that validates the line before writing it to `/output/entry.txt`: it must mention Monday, stay within 1–200 characters, hold 8–30 words, and carry its punchline turn — Monday itself calling in sick, and HR assigning me to cover its shift. The program reads the file back and only exits 0 when the bytes on disk match the joke exactly.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
